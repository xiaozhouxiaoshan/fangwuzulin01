
=== Spring Boot 框架 ===
- Spring Boot 是基于 Spring 框架的快速开发平台，能够通过约定优于配置的方式简化项目搭建与配置过程。该框架内置 Web 容器，支持快速构建 RESTful 风格的 Web 应用，具有开发效率高、可扩展性强等特点。
- 本系统后端采用 Spring Boot 作为核心开发框架，负责处理业务逻辑、接口请求及权限控制等功能。通过 Controller、Service 和 Mapper 分层设计，使系统结构清晰，便于后期维护和功能扩展。

=== MyBatis / MyBatis-Plus 持久层技术 ===
- MyBatis 是一种半自动化的 ORM 框架，能够通过映射文件或注解的方式实现 Java 对象与数据库表之间的映射关系。MyBatis-Plus 在 MyBatis 基础上进行了功能增强，提供了通用 CRUD 接口，减少了重复代码的编写。
- 在本系统中，持久层采用 MyBatis-Plus 进行数据库操作，实现了对房屋信息、租客信息、租赁合同、收租记录、报修数据等业务数据的高效管理，提高了开发效率和代码可读性。

=== 系统总体架构设计 ===
- 系统整体采用前后端分离架构。前端通过浏览器向后端发送 HTTP 请求，后端接收请求并进行业务处理后，将结果以 JSON 格式返回前端。前端根据返回数据进行页面渲染与交互处理。
- 系统在逻辑上分为表示层、业务逻辑层和数据访问层，各层职责明确，既保证了系统运行的稳定性，也为后续功能扩展提供了良好的结构基础。

=== 3.2.1 管理员功能需求 ===
- 管理员是系统的核心管理角色，主要负责基础数据维护与业务流程监管，其功能需求包括：
- （1）用户信息管理
管理员能够对租客信息进行查询、修改和删除操作，对户主信息进行统一维护与管理。
- （2）房屋信息管理
管理员可以对房屋基本信息进行增删改查操作，包括房屋编号、位置、租金等信息的维护。
- （3）看房申请管理
管理员能够查看租客提交的看房申请信息，并对申请进行审核与管理。
- （4）租赁合同管理
管理员可以对租赁合同信息进行维护，支持合同信息的查询与管理操作。
- （5）收租信息与统计管理
管理员能够维护收租记录，并通过统计功能对收租数据进行汇总与分析。
- （6）报修与维修数据管理
管理员可以查看租客提交的报修信息，并对维修数据进行管理与统计。
- （7）公告信息管理
管理员负责系统公告的发布与维护，为系统用户提供通知与提示信息。

=== 3.2.2 租客功能需求 ===
- 租客是系统的主要使用角色之一，其功能需求包括：
- （1）用户注册与登录
租客能够通过系统完成注册和登录操作，进入系统进行相关业务操作。
- （2）房屋信息浏览
租客可以浏览系统中发布的房屋信息，了解房屋基本情况。
- （3）看房申请提交
租客在浏览房屋信息后，可向管理员提交看房申请。
- （4）租赁信息查询
租客能够查询与自身相关的租赁合同及收租记录信息。
- （5）报修提交
租客可在租赁过程中提交房屋报修信息，便于后续维修处理。

=== 系统功能模块设计 ===
- 根据系统需求分析结果，并结合房屋租赁管理业务的实际流程，对系统功能模块进行整体划分。系统主要包括以下功能模块：
- （1）用户模块
实现系统用户的注册、登录及基本信息管理功能，支持普通用户与管理员的身份区分。
- （2）房源模块
用于对房屋基本信息进行管理，包括房屋的基本属性、房屋图片及相关说明信息。
- （3）租赁模块
实现房屋租赁申请、审核及租赁记录管理等功能，是系统的核心业务模块之一。
- （4）报修模块
用于租赁过程中房屋报修信息的提交、审核及维修状态管理。
- （5）留言模块
包括房屋留言、留言板等功能，便于用户之间及用户与管理员之间进行信息交流。
- （6）系统公告与轮播图模块
用于发布系统公告信息和首页轮播展示内容，提高系统的信息通知能力。
- （7）数据可视化模块
对租赁、报修等业务数据进行统计分析，并以图表形式进行展示，提升数据的直观性。
- （8）简易智慧推荐模块
基于用户浏览、收藏等行为数据，对房屋信息进行简单推荐，提高系统的智能化水平。

=== Token 拦截器设计 ===
- 系统采用基于 Token 的身份认证机制。用户登录成功后，系统生成对应的 Token 信息，后续请求需携带该 Token 进行身份验证。通过在后端配置拦截器，对请求进行统一拦截和校验，确保系统访问的安全性。

=== 文件上传设计 ===
- 系统支持文件上传功能，主要用于房源图片、相关附件的上传与存储。后端通过文件上传接口接收文件，并将文件路径保存至数据库中，实现房源图片的统一管理。

=== 智慧推荐模型设计 ===
- 系统基于用户的浏览、收藏等行为数据，对房屋信息进行简单统计分析，并根据用户行为特征进行房源推荐。该推荐模型属于简易智慧推荐方式，为系统后续智能化扩展提供基础支持。

=== 留言与论坛模块设计与实现 ===
- 留言模块为系统用户提供了信息交流的平台，包括房屋留言、留言板及租房论坛等功能。
- 普通用户可在房屋详情页面进行留言，向管理员或房东咨询相关问题；同时，系统还提供留言板及租房论坛功能，用户可发布帖子进行信息交流。管理员可对相关内容进行管理和维护，保障系统信息的规范性。
